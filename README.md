# Fuel Sales, Payment & Reporting Dashboard — SE2030

This package contains ONLY the assigned major function: **Fuel Sales, Payment & Reporting Dashboard**.

## Functions included
- Record fuel sales
- Select fuel and quantity
- Automatic unit price calculation from inventory
- Automatic fuel-stock reduction
- Payment method and payment status recording
- Invoice number generation
- Printable invoice
- Sales/transaction history
- Delete sale with stock restoration
- Dashboard analytics
- Paid revenue and paid transaction totals
- Fuel quantity sold summary
- Low-stock alerts
- Date-range sales reports
- Payment-method report
- Detailed sales report

## Run
```bash
mvn clean spring-boot:run
```
Open `http://localhost:8080`

The project includes a small H2 database and sample fuel inventory so this part can be demonstrated independently.
